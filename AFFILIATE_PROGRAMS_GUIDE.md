## 🔧 Implementation Template

### Add New Affiliate Program

**1. Create provider file:**
```javascript
// src/lib/affiliates/elevenlabs.js
export const ELEVENLABS_AFFILIATE = {
  id: "elevenlabs",
  name: "ElevenLabs",
  commission: 0.30,
  cookieDuration: 90,
  affiliateUrl: "https://elevenlabs.io/?ref=YOUR_CODE",
  pricing: {
    starter: { name: "Starter", price: "$11/month", earnings: "$3.30" },
    pro: { name: "Pro", price: "$99/month", earnings: "$29.70" },
  },
  features: ["Text-to-speech", "Voice cloning", "AI narration"],
};
```

**2. Add to affiliate dashboard:**
```javascript
// src/app/(app)/affiliate/page.jsx
const AFFILIATE_PROGRAMS = [
  POLLO_AFFILIATE,
  ELEVENLABS_AFFILIATE,
  DESCRIPT_AFFILIATE,
  // ... more programs
];
```

**3. Display in UI:**
```jsx
{affiliatePrograms.map(program => (
  <div key={program.id} className="card">
    <h2>{program.name}</h2>
    <p>Commission: {program.commission * 100}%</p>
    <p>Cookie: {program.cookieDuration} days</p>
    {/* Copy link, earnings calc, etc */}
  </div>
))}
```
